# Keyboard Wizard
Vimpire like игра обучающая слепой печати на 2х раскладках ru, en.
Можно как полностью овладеть навыку слепой печати, 
так и поддерживать свой уровень за счёт обычного режима с волнами врагов.

# Особенности
- Механика набора текста
- Удобная ходьба через зажатый SHIFT (Позволяет не убирать руки с позиции набора текста)

# Управление
- Клавиатура. ru, en раскладка.
- Ходьба "SHIFT + DFJK"
